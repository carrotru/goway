# 打給來公衛｜新主持人招募簡報

國立陽明交通大學公共衛生研究所 Podcast《打給來公衛》第二季新主持人招募用的動畫簡報網頁。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 簡報主頁（所有樣式、動畫、程式都在這一個檔案裡） |
| `intro.mp4` | 片頭影片（片頭A 壓縮版，約 1 MB） |
| `logo.jpg` | 節目 Logo |
| `line-qr.png` | 報名用 LINE QR code |

## 操作方式

- `→` / 空白鍵 / Enter：下一頁
- `←`：上一頁
- `F`：全螢幕
- 手機：左右滑動

第 1 頁會自動播放片頭，播完會自動跳到封面。

## 用 GitHub Pages 上線

1. 在 GitHub 建立新的 repository，把這個資料夾裡的所有檔案上傳（`index.html` 要放在最外層）。
2. 進入 **Settings → Pages**。
3. **Source** 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等 1–2 分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

也可以直接在電腦上雙擊 `index.html` 用瀏覽器打開。
